# Кейс 002: Тестирование API (Sortula — AI закладки, production)

**Что сделано:** интеграционное API-тестирование двух эндпоинтов production-сервиса — экспорт закладок и настройки пользователя.

**Контекст:** [Sortula](https://www.sortula.ru) — AI-powered закладочный SaaS в production. Пользователи сохраняют контент через Web, Telegram, VK и браузерное расширение; LLM автоматически расставляет теги, делает summary, определяет "срок жизни" материала. Стек: FastAPI + PostgreSQL + Redis + Celery.

**Роль в проекте:** Проектировала тест-сценарии и граничные случаи; верифицировала корректность каждого теста. Реализация тестов выполнена в связке с AI-агентом (Claude) — это современная практика QA-работы, при которой тестировщик отвечает за "что тестировать и почему", а агент — за имплементацию.

**Найдено дефектов:** 1 (Critical — баг в production-коде, обнаружен в процессе тестирования)

## Ключевые паттерны

- **Auth gate** — 401 без токена проверяется первым, до любой бизнес-логики
- **Empty state** — новый пользователь без закладок → корректный пустой ответ (не 500)
- **Content-type** — каждый format возвращает правильный MIME-тип
- **Content-Disposition** — браузер получает сигнал скачать файл, не показывать в окне
- **Error handling** — неподдерживаемый format → 400 с читаемым сообщением
- **Partial update** — PATCH обновляет одно поле, не сбрасывает остальные
